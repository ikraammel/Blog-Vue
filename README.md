# Blog Vue

A blog frontend built with Vue 3 and Vite.

## Tech stack

- JavaScript
- Vue 3
- Vite

## Run locally

```bash
git clone https://github.com/ikraammel/Blog-Vue.git
cd Blog-Vue
npm install
npm run dev
```
